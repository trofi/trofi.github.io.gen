Hello!

This is the source of <https://trofi.github.io/> blog.

# Navigating

- [`posts/`](./posts): posts source code in `.markdown` format.
- [`posts.data/`](./posts.data): post-specific images, example binaries
  and similar.
- [`src/`](./src): source code for the site generator itself.
- [`run_watcher.sh`](./run_watcher.sh): main script to generate site
- [`trofi.github.io`](https://github.com/trofi/trofi.github.io/):
  repository in [GitHub pages](https://pages.github.com/) format with
  autogenerated content.

# Trying It Out

Just clone this repo and run a [`run_watcher.sh`](./run_watcher.sh) and see what happens:

```
# optional, start a `nix` developmen shell to pull in all dependencies:
$ nix develop --no-write-lock-file

$ git clone https://github.com/trofi/trofi.github.io.gen
$ cd trofi.github.io.gen/
$ nix develop --no-write-lock-file
$ ./run_watcher.sh
...
    Finished `release` profile [optimized] target(s) in 0.08s
     Running `target/release/site`
```

Now you can visit `./out` directory and explore the result in the browser.

Caveat: [`run_watcher.sh`](./run_watcher.sh) relies on a few dependencies:

- `rustc`, `cargo` and a few `rust` libraries (see
  [`Cargo.toml`](Cargo.toml))
- `graphviz`
- `gnuplot`
- `inotify-tools`
